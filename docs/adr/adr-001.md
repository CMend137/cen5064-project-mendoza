# ADR-001: Build MacroMetric as a Python nutrition tracking application

**Date:** 2026-09-21
**Status:** accepted

## Context

MacroMetric is a nutrition and progress tracking application that will allow users to calculate personalized calorie and macronutrient targets, log daily intake and body weight, view weekly trends, and receive progress recommendations. The project must remain manageable within the scope of the semester while supporting the four core use cases defined for the application.

## Decision

MacroMetric will be developed in Python using a layered structure that separates the presentation, service, domain, and data responsibilities of the application. This structure will allow each part of the system to be developed and tested independently as the project grows.

## Consequences

This decision keeps the project organized and makes it easier to add features without placing all of the application logic in one location. It also makes the individual components easier to test and maintain. The layered structure adds some additional organization and files compared with a simpler application, but it should make later development easier as MacroMetric becomes more complex.
